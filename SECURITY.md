# Security

Report vulnerabilities privately through this repository's Security tab: [Report a vulnerability](https://github.com/abdelrahmanzied/claude-muslim/security/advisories/new).
Never report them in a public issue, pull request or discussion.

Include:

- The affected version, shown by `/muslim`.
- The surface: terminal or desktop.
- Your OS.
- Steps to reproduce.
- The impact.

Only the latest release is supported with security fixes.
