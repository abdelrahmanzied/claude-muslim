# Changelog

## 0.2.0

- Thikr line: tasabih replace Claude's working words, in a fixed order per moment (starting, thinking, writing), 3 s per phrase.
- End of turn: تَمَّ بِحَمْدِ اللَّهِ.
- Usage limit: حَسْبِيَ اللَّهُ وَنِعْمَ الْوَكِيلُ above the prompt in Claude orange until the limit resets.
- `/thikr` command: on/off, speed, tashkeel, end. Settings also in `/config`.
